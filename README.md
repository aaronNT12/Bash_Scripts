# Bash Scripting & Linux Automation

Collection of foundational scripts, exercises, and system administration tasks built to master Bash scripting from scratch.

## 📂 Repository Structure
* `01-basics/`: Introduction to variables, conditional statements, and loops.
* `02-automation/`: System utility scripts for file management and routine backups.
* `03-sysadmin/`: User management, permissions, and log monitoring exercises.

## 🛠️ Environment & Tools
* **Shell:** Bash (GNU Bourne-Again SHell)
* **OS Environment:** Linux / UNIX-like systems (compatible with Windows WSL)

## 🎯 Goal
Build practical shell scripting skills to automate administrative tasks and reinforce Linux system fundamentals.
